# 🚀 QuickLaunch - Customizable Shortcut Extension

QuickLaunch is a premium, highly configurable Chrome extension that transforms your new tab or popup into a streamlined, beautiful grid of your favorite website shortcuts.

![QuickLaunch Banner](https://raw.githubusercontent.com/GitPrathameshKadam/quicklaunch/main/icon.png)

## ✨ Features

- **📱 Customizable Grid**: Control exactly how many rows and columns appear in your shortcut grid.
- **🎨 Visual Precision**: Adjust font sizes, grid gaps, and toggle shortcut titles to match your aesthetic.
- **🌗 Theme Support**: Native Dark, Light, and System theme support with a premium Glassmorphism design.
- **🔍 Instant Search**: Quickly filter through your shortcuts with a built-in, lightning-fast search bar.
- **🖱️ Drag & Drop**: Intuitively reorder your shortcuts in the options menu to prioritize your most-used sites.
- **🌐 Smart Favicons**: Automatically fetches and persists high-quality favicons for a visual browsing experience.
- **⚡ Performance First**: Lightweight manifest v3 extension with zero dependency overhead.

## 🛠️ Installation

### For Developers (Manual Load)
1. Download or clone this repository.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the folder containing the extension files.

## 🚀 Usage

1. **Open QuickLaunch**: Click the extension icon in your toolbar to open the shortcut grid.
2. **Search**: Start typing immediately to filter your shortcuts.
3. **Add/Edit**: Click the settings icon (⚙️) to open the dashboard.
4. **Organize**: In the dashboard, use the drag handle to reorder shortcuts or use the "Add Shortcut" button to expand your grid.

## ⚙️ Configuration Options

- **Grid Layout**: Set custom Rows (1-10) and Columns (1-10).
- **Appearance**: 
  - Toggle Shortcut Titles.
  - Custom Font Size (10px - 20px).
  - Adjustable Grid Gap (8px - 32px).
- **Theming**: Switch between Dark, Light, and System modes.
